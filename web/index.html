tower

Air traffic control for AI coding agents working on one Git repository at the same time.

Each agent files a flight plan naming every path it will change. Tower grants it a lease on those paths, or holds it in line behind whoever already has them. A cleared agent works in its own fork, and tower lands the change on trunk only if it stayed inside its lease. Two agents never edit the same file at once, so there are no merge conflicts: they are prevented up front, not resolved afterwards.
